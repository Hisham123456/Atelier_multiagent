# Une table de coordination lisible

Mode : Operate. Hypothèse visuelle d'implémentation, sans référence graphique fournie.

Sources envisagées : édition de manuels, signalétique d'université, index de bibliothèque,
cartographie, cahier de recherche, identité de médiathèque, affiches culturelles. Direction
retenue : médiathèque, avec une typographie accueillante, un bleu profond et des surfaces claires.
La mise en page reste celle d'une application : historique, mission, équipe, résultats.

Palette : encre #17304b ; bleu #215f9c ; ciel #edf3f8 ; papier #ffffff ; ocre #ad6614 ;
vert #246347 ; alerte #a33242. Typographie : Onest si disponible, sans-serif de repli.
Espacement de base : 8px ; rayon des panneaux : 14px ; boutons : 8px.

Signature : l'équipe est montrée comme une liste de rôles dont les points d'activité et les
étiquettes évoluent réellement. La liaison possède sa propre zone de dialogue, jamais une fenêtre
qui masque le travail. Le journal explique les décisions sans afficher de raisonnement interne.

Les décisions simulées, tokens absents et coûts non configurés portent un libellé explicite.
Les erreurs proposent une action. Les états d'attente utilisateur sont distincts des travaux actifs.
Le suivi ne pose de questions qu'aux grandes étapes. Pas d'interrogations périodiques.
